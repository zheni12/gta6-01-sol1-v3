Built for make.fun's "Make GTA 6" bounty: [make.fun/bounty/gta6-01](https://make.fun/bounty/gta6-01)

**SOLMAR HEAT** is a complete, original open-world crime game that plays
in a desktop browser from static files — no build step, no network, no
assets on disk. Everything is procedural: the island city of Solmar Bay,
its five districts, traffic, pedestrians, police, missions, combat and
even the music are generated by the code in this repository.

You are **Ren Kadir**, a courier with a past, running jobs for the fixer
**Madame Okafor** across a sun-soaked island: steal the coupe, run the
parcels, vanish from the SBPD, wreck a rival crew, win the Harbor Sprint,
run the Heights at night, and take the Marina job out past the buoy —
then keep working the bay in free roam.

## Version 3

- **Marked streets** — every avenue and street now wears a continuous
  pale kerb line along both edges and a brighter, bolder centre dash, so
  the road grid reads as finished city streets from any angle.
- **A denser cover frame** — the Strand chase is staged with the full
  six-unit SBPD response (flankers, a smoking interceptor, a roadblock
  and CONDOR-EYE overhead), a cab alongside the hero coupe, streaming
  traffic both ways and a crowd on the boardwalk.
- **A packed market fight** — the Old Market frame gains a fifth stall,
  crate cover, a second fallen rival and return tracers crossing the
  lane both ways.
- **A night frame** — the title still is replaced by a fourth playable
  scene: Night Run downtown after dark, lit towers and lamps, two-way
  traffic and two stars on the panel.

## What is in the game

- **A living island city** — five districts (The Strand, Old Market,
  Downtown, Marina, The Heights) on a real road grid with crosswalks,
  lamps, palms, market stalls, piers and boats; a full day/dusk/night
  cycle with lit windows after dark.
- **Driving and stealing** — 32 traffic cars circulate the grid, 38 more
  sit parked and stealable; six body styles with arcade handling, damage
  and smoke.
- **On foot** — sixty pedestrians stroll the sidewalks and scatter from
  gunfire and speeding cars.
- **Wanted system** — one to five stars; named SBPD units (KESTREL-1,
  OTTER-2, VIPER-4, PALMA-3, CONDOR-EYE the helicopter, foot officers and
  roadblocks) pursue, shoot and corner you into a BUSTED meter.
- **Combat** — fists, the Kestrel-9 pistol and the Brute scattergun, with
  tracers, muzzle flash and rival crews who fight back.
- **A crew of three** — Mira Solano (Ghost Plates, Q), Theo Lindqvist
  (Quick Fix, R), Kiki Amara (Eyes Out, C), each on a cooldown.
- **Seven story missions** plus endless courier and sprint jobs, medals
  per mission, a rank/RP ladder, twenty golden Solmar stars to find and
  four stunt ramps that score your leaps.
- **A real dossier** — Tab opens the pause dossier: a street map drawn
  from the actual road network with the route to your objective, a
  completion ring, checklist, career stats, story ratings and three
  save slots (localStorage), whose summaries also appear on the title
  screen.
- **Synthesized sound** — three procedural radio stations, engine and
  siren voices and every effect are WebAudio; the game ships no audio
  files.

## Controls

| Input | Action |
| --- | --- |
| W A S D / arrows | Walk, drive, steer the boat |
| Mouse | Orbit camera, aim |
| Click | Fire / punch |
| E / F | Enter or leave a car, board the boat |
| Space | Brake (in a car), hop (on foot) |
| Shift | Sprint on foot |
| 1 / 2 / 3 | Fists / Kestrel-9 / Brute SG |
| Q / R / C | Crew abilities: Ghost Plates / Quick Fix / Eyes Out |
| T | Cycle the radio (in a car) |
| Tab / P / Esc | Pause dossier |

## Run it

```sh
node serve.ts          # then open http://localhost:8080
```

Any static file server pointed at `game/` works just as well. The game
needs no install and makes no network requests after loading.

Hand the entry in (what the bounty runs):

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts   # copies game/ + screenshots/, writes out/dossier.json
```

## Tech notes

- Plain ES modules under `game/src/`, one job per file; three.js is
  vendored as `game/vendor/three.min.js` and loaded with a classic
  script tag; everything else is hand-written for this game.
- The city is generated from a single seed (`?seed=`), so every player
  gets the same Solmar Bay; `?shot=<name>` stages the four screenshots
  deterministically — see `scripts/shoot.mjs` and `shots.json`.
- `main.ts` (Node 22, standard library only) assembles the entry and
  writes its dossier with the kit's `vendor/makefun-game.ts`
  `buildDossier`, byte-identical to the scorer's copy.
- All names, characters, places, vehicles and music are original to
  this game. No third-party game assets are used.
